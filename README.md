## `$ cat about.txt`

**EN —** I build Telegram and Bale bots, automation tools and small apps, mostly in **Python**: a media downloader, a casting/resume bot, a language-learning bot (Chinese · German · Russian), a gym coach bot, a shop chatbot, a sticker maker, trading bots for MetaTrader 5, and a Persian car-maintenance app. I'm leveling up on **DevOps**: containers, CI/CD, Linux and Kubernetes.
